# @deepseek-ai/dsh-client-ui-agents

[English](README.md) | 中文

Agents 渲染当前打开会话下方正在运行的子代理树——也就是工作区浏览器的 `sessionVisible()` 特意从普通会话列表中隐藏、并折叠为单个运行数徽章的那些会话。子代理会按照运行时自身记录的 `origin`/`parentId` 世系嵌套在其直接父级之下，可嵌套任意深度；排序上运行中的子代理优先，其余按最近更新排序。每一行显示子代理的标题、一个表示运行中/已停止/已中断/出错/已完成/空闲的状态点，以及——对于自身也带有子代理的会话——一个用于展开或折叠该嵌套分支的折叠开关。该视图只读：行内不提供导航，也没有停止控制，因为该视图未来将驱动的级联停止 RPC 属于另一条尚未落地的开发线；把操作接入此视图是刻意留待之后的工作，而非本次任务的一部分。当某个会话下方没有子代理时，视图会渲染一句明确说明，而不是一个空白面板。该包不提供 service，也不声明 Context 合并；它会在会话的 `'conversation.view'` slot 环中注册一个标签页，并通过框架标准的 `useSessions` hook 读取会话列表。约定：api-contracts v3 §8。

## 模型体验

无。Agents 视图只渲染浏览器中已保留的会话列表元数据。

#### KV 缓存影响

无；该包既不组装也不发送 provider 请求。

## 已知限制与延后工作

- **只读**——无法从此视图停止、中断或打开某个子代理；这些是级联停止 RPC 落地后有意留待之后的工作。
