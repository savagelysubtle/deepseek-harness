# @deepseek-ai/dsh-client-ui-settings-tools

[English](README.md) | 中文

Web 设置中的**工具**标签页，是“模型”“智能体预设”“插件”分区的同级分区。浏览器插件注册一个 id 为 `tools` 的本地化 `settings.section` 贡献；该分区拥有自己的导航入口。它为 Host 状态注册表（[`@deepseek-ai/dsh-mcp-client`](../../mcp/mcp-client/README.md)，仅通过 [`api-remotes`](../../api/remotes/README.md) 的 `mcp` Remote 命名空间访问）中登记的每个 MCP 服务器渲染一行，包含纯文字的连接状态标签、最后一次错误文本（如有），以及该服务器可能需要的操作。

每行的操作均由状态驱动：**授权**仅在服务器需要授权或已放弃重连时出现,会在点击处理函数中同步打开一个空白标签页,随后再 await `mcp/authorize-start`,仅在该调用成功返回后才把该标签页导航到返回的授权 URL——因为在 `await` 之后才打开的标签页会丢失大多数浏览器要求的用户手势标记，从而被拦截。**重连**仅在服务器已放弃重连时出现，重试一次连接。**启用/停用**切换调用 `mcp/set-enabled`；停用前会先通过共享的 `RiskConfirmation` 组件要求显式确认，启用则是立即生效。任何被拒绝的操作都会用该行自己的内联文字替换为失败信息，绝不静默失败；被拒绝的授权调用还会关闭它打开的标签页。列表在挂载时和用户点击“刷新”时加载，此后无需重新加载即可通过 `mcp/status-changed` 事件保持实时更新。

## 模型体验

无，因为本包只在浏览器设置中展示并操作 Host 拥有的 MCP 连接注册表，不注册任何模型接口。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **无批量操作** —— 每个操作（授权、重连、启用、停用）只针对单个服务器；没有多选或整表重试。
- **启用/停用读取的是 Loader 挂载状态，而非专用标志** —— 一行是否渲染为“已停用”完全来自 `McpServerStatus.state`，因为 `mcp/status` 本身并不单独发出 Loader 停用信号。
